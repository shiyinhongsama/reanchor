# 实盘操作手册：日线 EMA 回调策略（5% 风险 + VT25%）

> 版本 1.0 · 2026-11 · 配套研究：《加密货币永续合约 EMA 斜率趋势策略的稳健性验证》
> 本手册是该论文第 4.9 节收敛出的定投载体配置的落地执行文档。所有规则与回测引擎逐条对应，不得临场发挥。

| 项目 | 参数 |

## 2. 账户与资金结构

1. 三个独立子账户（交易所子账户功能或三个账号均可），分别只交易 BTCUSDT、ETHUSDT、SOLUSDT 永续。
2. 初始资金三等分。例：总本金 1,000 U → 每子账户 333 U。
3. 每个子账户合约设置为 **逐仓、杠杆 3x**。杠杆设置只是上限，实际仓位由第 5 节公式决定，通常远低于 3x。
4. 子账户之间**禁止互相调拨**，赢亏各自复利。每月定投是唯一的再平衡入口（第 7 节）。

## 3. 每日 SOP（收盘后 10 分钟，三个品种各一遍）

> 时间点：每日 UTC 00:00 K 线收盘后（北京时间 08:00），任一固定时间执行即可，重要的是每天在 K 线收盘之后、下根 K 线开盘初期完成。

1. 更新该品种的日线数据（交易所导出或用任意行情软件，CSV 列：`open_time,open,high,low,close`）。
2. 更新本子账户权益记录（一行：日期 + 当前权益，含浮动盈亏）。
3. 运行信号脚本：

```bash
# 空仓时
python live_signal.py --csv BTCUSDT_1d.csv --equity 当前权益 --eq-hist equity_btc.csv

# 持仓时（多单示例）
python live_signal.py --csv BTCUSDT_1d.csv --equity 当前权益 --pos long --entry-stop 开仓时的初始止损价
```

4. 按脚本输出的【操作】执行：
   - 「明日开盘平仓」→ 下一个 K 线开盘时段以市价/限价单平仓；
   - 「继续持有」→ 把止损单调整到输出的重锚价（初始止损价不变，仍是底线）；
   - 「开仓」→ 见第 5 节。
5. 记录当日操作到交易日志（见附录模板）。

**纪律：每天只操作这一次。不看 1h/4h 图，不根据盘中波动加减仓。策略的收益来源是"慢"，任何盘中干预都是在给回测验证过的统计性质掺水。**

## 4. 指标与信号定义（与回测引擎逐字一致）

```
EMA20   = 收盘价的 20 日指数移动平均
斜率    = EMA20[今日] − EMA20[8 日前]
ATR14   = TrueRange 的 Wilder 14 日平滑（alpha = 1/14）
```

**做多入场**（以下全部在"最新已收盘 K 线"上判定）：
1. 前一根 K 线收盘 > 其 EMA20（原本在均线上方）；
2. 最新 K 线最低价 ≤ EMA20（盘中回踩过均线）；
3. 最新 K 线收盘 > EMA20（收回来了）；
4. 斜率 > 0（均线方向向上）。

**做空入场**：全部镜像（前收 < EMA20；最新最高 ≥ EMA20；最新收 < EMA20；斜率 < 0）。

**出场**（满足任一即走）：
- 斜率翻转：多单见斜率 < 0 / 空单见斜率 > 0 → 次日开盘平仓；
- 重锚止损：3×ATR 止损盘中触发（第 6 节）。

**没有止盈。** 让止损替你下车。

## 5. 开仓流程与仓位公式

信号确认后，**次日开盘**执行：

```
止损距离 dist   = 3 × ATR14
风险金额 risk   = 子账户权益 × 5% × VT系数
开仓数量 qty    = risk / dist
名义价值        = qty × 开仓价
杠杆            = 名义价值 / 子账户权益   （超过 3x 则按 3x 截断，qty 等比缩小）
初始止损价      = 开仓价 ∓ dist（多单减，空单加）
```

**VT 系数**：取子账户最近 20 条日权益收益率，年化波动 σ = 日收益标准差 × √365，则
`VT系数 = clamp(0.25 / σ, 0.25, 2.5)`。权益记录不满 20 天时 VT 不启用（系数 = 1）。

**示例**（BTC 子账户，权益 3,500 U，VT 系数 0.85，ATR = 2,100，价格 77,500）：
- dist = 6,300（约 8.1%）
- risk = 3,500 × 5% × 0.85 = 148.75 U
- qty = 148.75 / 6,300 ≈ 0.0236 BTC ≈ 名义 1,830 U ≈ 0.52x 杠杆
- 挂多单 + 止损单 71,200

开仓后立即做三件事：① 挂止损单；② 记录**初始止损价**（之后每天重锚的下限）；③ 写日志。

## 6. 持仓期管理：重锚止损（v1 规则）

规则（每日收盘后更新，脚本自动算）：

```
斜率与持仓同向时：
多单：止损 = max(初始止损, 当日收盘 − 3×ATR)
空单：止损 = min(初始止损, 当日收盘 + 3×ATR)
```

要点：

- **以当日收盘重锚，而不是锚定历史最高价**。只要斜率还站在持仓方向，趋势就算健康，回撤给它 3×ATR 的呼吸空间——这个规则在 9 格参数平台上 7 格跑赢旧的 peak 锚定法，三品种年化均值 +25.2% → +26.6%，止损误杀率从 39% 降到 12%；
- **初始止损是不可逾越的底线**：重锚只放大浮盈的回撤容忍度，绝不放大开仓时的既定风险；
- 止损单**必须真实挂在交易所**（触发即市价），不要"心里止损"；
- 资金费：每日 3 个结算时点从账户划扣，金额小但会在日志里体现，属预期内成本（回测已含 0.01%/8h）。

## 7. 定投日操作（每月第一个交易日）

1. 向总账户转入 500 U（或当月预算），三等分注入三个子账户。
2. 入金当日记入各子账户权益曲线，但**当天不做任何"因为入金"的交易**——新资金自然参与下一次信号的仓位计算。
3. 每 12 个月做一次权益曲线复核：若某子账户权益超过另一子账户 2 倍，允许一次性再平衡至等权（平时不动）。

**定投纪律**：下跌月份照常扣款。滚动窗口验证中，最差起点的 24 期定投仍以正收益收尾，靠的正是回撤期的持续扣款。停扣一次，统计性质就破一次。

## 8. 成本预算（回测假设，实盘应优于或不差于此）

| 成本项 | 回测假设 | 说明 |
|---|---|---|
| 手续费 | 0.05% / 边 | Binance VIP0 挂/吃单以内，BNB 抵扣后更低 |
| 滑点 | 0.02% / 次 | 开盘市价单的实际偏离 |
| 资金费 | 0.01% / 8h | 长期均值假设，极端期会更高，属持仓成本 |

年交易频率参考：每子账户约 40–50 笔/年，成本对结果的影响已在全部回测数字中扣除。

## 9. 监控与关停规则（这部分和开仓规则同等重要）

1. **年度平台扫描**（每年一次）：用最新数据重跑 EMA15–30 × k3–8 的 16 格参数扫描。
   - 参数平台存续（多数格子仍为正）→ 不动；
   - 平台明显萎缩或消失 → 该品种降仓 50%；连续两次扫描消失 → 停用该品种。
2. **回撤熔断**：组合净值自高点回撤达到 **-33%**（v1 规则下历史最大 -30.2% 的 1.1 倍）→ 全部仓位减半；回撤达 **-45%** → 清仓停用，进入复盘。
3. **环境异常**：交易所宕机、资金费率连续一周极端（|费率| > 0.1%/8h）、品种被下架风险 → 该子账户暂停开新仓，持仓正常管理。
4. **任何"优化"冲动**：规则修改必须重新走完整回测流程（样本外 + 熊市压力 + 滚动起点），禁止边实盘边调参。

## 12. 风险提示

本策略历史回测与滚动窗口验证不构成未来收益承诺。主要风险：连续震荡市磨损（2025 年全年接近零收益是正常形态）、跳空越过止损造成的超额亏损、交易所与稳定币对手方风险、以及最大的人性风险——在 19 个月水下期放弃纪律。请只用可承受全部损失的资金执行本策略。
